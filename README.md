## 🗃 Como visualizar?
Cada pasta do repositório guarda atividades referentes a um conteúdo geral estudado.

⚠️ **Arquivos .fig são padrão do aplicativo [Figma](https://www.figma.com/pt-br/), que é uma ferramenta poderosa de design digital para desktop e web.**

⚠️ **Arquivos .xcf são padrão do aplicativo [Gimp](https://www.gimp.org/downloads/), que é um editor de imagens popular e gratuito.**

## ❓ UX & UI
Dentro da área de design digital para desenvolvimento, existem duas vertentes de atuação que muitas vezes são confundidas.

 **User Experience (UX) ❌ User Interface (UI)**

O designer UX estuda a experiência geral do usuário no sistema, implementando alterações de usabilidade e otimização no produto. 

Está relacionado ao UX: 
    
- 🔲 Organização e simplicidade dos elementos
- 🔀 Fluxo de navegação intuitivo
- 👁‍🗨 Ferramentas de acessibilidade e suporte
- 🎯 Parte funcional do design

O designer UI monta a aparência das telas do sistema, criando interfaces visuais que conversam corretamente com os usuários.

Está relacionado ao UI:

- 🎨 Uso inteligente de cores, formas e ícones
- 🖼 Criação de identidade visual
- 📐 Responsividade e legibilidade das interfaces
- 🖌 Parte estética do design

## ✒ Fundamentos do Design 

Existem alguns princípios praticamente universais dos designers (especialmente os digitais) que devem ser seguidos para garantir uma estética coerente e interessante:

- ↔️ **Proximidade**: elementos similares devem aparecer próximos uns dos outros, formando grupos
- 📐 **Alinhamento**: o conteúdo deve ser organizado com um alinhamento mínimo entre os elementos, facilitando a leitura
- 📖 **Espaço em branco**: espaços vazios devem contornar elementos importantes para gerar destaque
- 🚦 **Hierarquia**: enfatiza alguns elementos em detrimento de outros, direcionando a navegação (principalmente em textos)
- 🔳 **Contraste**: diferencia elementos de diversas formas para gerar destaque (trabalha junto com a hierarquia)
- 🔄 **Repetição**: repete elementos ou um estilo, gerando familiaridade
